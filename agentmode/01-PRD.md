# 01 · Product Requirements Document (PRD)

## 1. 产品概述

### 1.1 产品名称
AI 创意绘画助手（暂定）

### 1.2 产品定位
一个以对话为核心的 AI 绘画协作平台。区别于市场上"输入 prompt → 生成图片"的翻译机模式，本产品的核心价值在于：**像一个真正的创意设计师一样，与用户协作完成从模糊意图到高质量图像的全流程。**

### 1.3 目标用户

| 用户类型 | 特征 | 核心诉求 |
|---|---|---|
| 内容创作者 | 有创意想法但缺乏设计能力 | 快速将脑海中的画面变为现实 |
| 产品/运营人员 | 需要商业用图但不懂 prompt | 描述业务场景直接出图 |
| 设计师 | 有专业背景，想提升效率 | 快速出概念图，快速迭代 |
| 普通用户 | 好奇心驱动，随意探索 | 低门槛体验 AI 绘画乐趣 |

---

## 2. 核心问题与解决方案

### 2.1 现有产品的问题

1. **门槛高**：用户需要学习 prompt 语法，不懂专业词汇就出不了好图
2. **流程割裂**：想法 → prompt 这一步完全靠用户自己，平台不参与
3. **固定询问流程**：部分 AI 助手设置了固定的 2-3 步问答，用户已描述清楚仍要走完流程，体验差
4. **无创意协作**：系统不会主动提案，不会补充用户没想到的细节
5. **结果无反馈闭环**：生成后不知道哪里好哪里不好，只能凭感觉重试

### 2.2 本产品的解决方案

| 问题 | 解决方案 |
|---|---|
| 门槛高 | 用户只需说自然语言，LLM Agent 负责翻译为专业 prompt |
| 流程割裂 | Agent 主动参与创意讨论，补充用户未考虑的维度 |
| 固定询问 | Decision Engine 动态评估信息完整度，信息充分则直接生成 |
| 无创意协作 | Agent 有"提案"能力，会主动给出创意方向供用户选择 |
| 无反馈闭环 | VLM Critic 自动分析生成结果，提取结构化反馈指导迭代 |

## 3. 核心功能需求

### 3.1 智能对话创作（P0）

- 用户用自然语言描述需求，支持中文
- Agent 动态判断信息是否足够，**不做固定轮次的追问**
- Agent 可主动提出创意方案，用户选择或调整
- 确认方案后一键生成

**验收标准：**
- 用户描述充分时（如"赛博朋克风格的猫坐在霓虹灯下"），0 次追问直接生成
- 用户描述模糊时（如"画张商业用图"），最多追问 1-2 次，每次只问一个问题
- Agent 每次回复中必须有推进感，不能停留在原地反复追问

### 3.2 创意方案确认（P0）

- 生成前展示结构化的 Creative Brief（创意摘要）
- 包含：核心概念、视觉元素、风格定义、色彩方向
- 用户可确认或要求调整某个具体项目

### 3.3 图像生成与展示（P0）

- 支持多种主流图像生成模型（通过 Image Provider 抽象层）
- 生成过程中展示 loading 状态
- 生成完成后图片与对话上下文关联展示
- 支持图片下载

### 3.4 智能迭代（P0）

- 用户对生成结果给出自然语言反馈
- VLM Critic 解析反馈 + 分析当前图像
- 生成结构化 diff（保留什么、修改什么）
- 基于 diff 更新 prompt 重新生成

### 3.5 项目管理（P1）

- 每次创作会话作为一个"项目"保存
- 保留完整的对话历史和所有生成版本
- 支持从历史项目继续创作

### 3.6 风格探索（P2）

- 提供风格灵感库（赛博朋克、水彩、油画、极简等）
- 用户可以上传参考图，Agent 分析风格后融入生成

---

## 4. 非功能需求

### 4.1 性能

| 指标 | 目标 |
|---|---|
| LLM 首字响应 | < 1s（流式输出） |
| 图像生成时间 | < 15s（取决于 Provider） |
| VLM Critic 分析 | < 3s |

### 4.2 用户体验

- 所有 LLM 回复必须流式输出，不能等待完整响应
- 图像生成期间 UI 有明确进度反馈
- 移动端友好

### 4.3 可扩展性

- Image Provider 为抽象层，可随时接入新的图像生成服务
- LLM 层可切换模型，不与特定服务商强绑定

## 5. 用户故事

### Story 1：清晰需求，零追问直接生成
> 用户："画一张赛博朋克风格的城市夜景，雨后的街道倒映霓虹灯"
>
> 期望：Agent 理解意图，确认一下方案，直接生成，无多余问题

### Story 2：模糊需求，最少追问引导
> 用户："帮我画张放官网首页用的图"
>
> 期望：Agent 问"你们是做什么方向的业务？" → 用户回答 → Agent 提出创意方案 → 用户确认 → 生成

### Story 3：主动提案
> 用户："我想要一张科技感的图，但不太确定要什么风格"
>
> 期望：Agent 主动说"我有三个方向你参考一下：A/B/C，你倾向哪个？"

### Story 4：迭代调整
> 用户看到生成结果："颜色太暗了，人物脸部不够清晰"
>
> 期望：Agent + VLM Critic 分析问题，调整 prompt 相关参数，重新生成，保留其他满意的部分

## 6. 成功指标

| 指标 | 定义 | 目标 |
|---|---|---|
| 平均询问轮次 | 从开始到首次生成的对话轮数 | ≤ 2 轮 |
| 首次生成满意率 | 用户对第一张图表示满意的比例 | ≥ 40% |
| 迭代次数 | 每个项目平均迭代轮数 | 2-4 轮 |
| 会话完成率 | 开始对话后成功生成至少一张图的比例 | ≥ 70% |
