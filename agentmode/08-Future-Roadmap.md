# 08 · Future Roadmap

## 前提

本文档描述 MVP 验证成功后的演进方向。所有规划都以**核心体验：创意协作**为轴心延伸，不做功能堆砌。

---

## Phase 1 · 体验深化（MVP + 1-2 个月）

**目标：** 把核心体验做到行业最佳。

### 1.1 高级 VLM Critic

```
当前 MVP：基础质量检测 + 简单反馈解析

升级为：
- 多维度评分（构图 / 光线 / 主体清晰度 / 色彩和谐 / 风格一致性）
- 跨迭代对比（v1 vs v2 哪里进步了，哪里退步了）
- 主动发现用户没有注意到的问题
- 针对不同用途（商业图/个人头像/插画）的专属评估维度
```

### 1.2 参考图支持（Image-to-Image）

```
用户可以：
- 上传参考图，描述"类似这种风格"
- VLM 自动分析参考图的风格特征
- 上传草图，AI 精细化渲染
- 上传已有图片，局部修改（Inpainting）
```

### 1.3 Creative Brief 增强

```
当前 MVP：文字版 Brief，用户确认

升级为：
- 可视化 Brief（色板 + 风格参考图 + 构图示意）
- Brief 中每个要素单独可编辑
- Brief 版本历史（记录用户调整了哪些）
```

### 1.4 智能追问质量提升

```
当前 MVP：基于规则的追问优先级

升级为：
- 基于历史数据分析"哪类追问对结果提升最大"
- 个性化追问（根据用户历史偏好调整追问策略）
- 更自然的追问方式（提案式 vs 问题式 动态选择）
```

## Phase 2 · 能力扩展（+3-4 个月）

**目标：** 从"聊天生图"扩展到"全流程创意工作台"。

### 2.1 多模型路由

```
不同任务自动选择最适合的模型：
- 写实人像     → Stable Diffusion XL + 专用 LoRA
- 插画/漫画    → NovelAI / FLUX Dev
- 概念图/草稿  → FLUX Schnell（速度优先）
- 商业产品图   → Midjourney API（质量优先）

模型路由逻辑放在 Image Provider 抽象层，对上层透明。
```

### 2.2 风格系统

```
内置风格库（50+种）：
- 用户可以浏览和收藏风格
- 支持风格混合（"50% 赛博朋克 + 50% 水彩"）
- 用户可以从自己满意的图中提取风格，保存为自定义风格
- 风格可以在项目间复用
```

### 2.3 系列图生成

```
场景：用户需要一组风格统一的图（如品牌物料）

功能：
- 从一个创意 Brief 生成多张构图不同但风格统一的图
- Agent 自动规划"这组图需要哪些角度/构图"
- 批量生成 + 批量迭代
```

### 2.4 提示词透明化

```
面向进阶用户：
- 查看每次生成使用的完整 prompt
- 手动微调 prompt 后重新生成
- 收藏优质 prompt 模板
- 理解 AI 的"翻译"逻辑（用于学习）
```

## Phase 3 · 平台化（+5-8 个月）

**目标：** 从工具变成平台，构建网络效应。

### 3.1 创作社区

```
- 用户可以公开分享作品（含 Creative Brief）
- 浏览他人作品并一键"基于此风格创作"
- 作品收藏 / 点赞 / 评论
- 热门风格 / 热门主题 trending
```

### 3.2 模板市场

```
- 专业设计师发布 Creative Brief 模板
- 模板包含：创意方向 + 参考图 + 推荐参数
- 普通用户购买/使用模板（设计师分成）
- 典型模板：电商产品图、游戏角色图、品牌海报...
```

### 3.3 Agent 定制化（面向企业）

```
企业可以定制专属 Agent：
- 注入品牌规范（品牌色 / 禁用元素 / 风格指南）
- 定制化 System Prompt（对齐企业业务场景）
- 私有化模型（企业自有 LoRA / Fine-tuned 模型）
- 团队协作（多人在同一项目上协作）
```

### 3.4 API 开放（面向开发者）

```
开放核心能力：
- 对话式图像生成 API（LLM Agent + 图像生成完整链路）
- Webhook（生成完成后回调）
- SDK（JavaScript / Python）

使用场景：
- 第三方产品集成 AI 绘画能力
- 游戏、电商、内容平台的 AI 图片生成
```

## Phase 4 · 多模态扩展（长期）

**目标：** 不仅是绘画，而是全面的视觉创意 AI。

### 4.1 视频生成

```
从图像延伸到视频：
- 基于已有图片生成短视频（图生视频）
- 关键帧动画（Agent 规划镜头语言）
- 风格一致的多段视频串联
```

### 4.2 3D 资产生成

```
- 从 2D 图生成 3D 模型
- 游戏资产、产品展示、建筑可视化
- 与 Blender / Unity 集成
```

### 4.3 多模态创意工作流

```
整合多种创意工具的 Agent：
- 图像 → 文案（品牌图 + 配套文案）
- 文案 → 图像（广告文案自动配图）
- 设计稿 → 代码（UI 设计直出前端代码）
```

## 技术演进方向

### 模型层

```
短期：完全依赖第三方 API
中期：Fine-tune 专用 LoRA（更好的风格控制）
长期：自有模型或模型联盟（成本 + 质量控制）
```

### Agent 层

```
短期：单一 LLM Agent
中期：多 Agent 协作（创意 Agent + 执行 Agent + 质检 Agent 分工）
长期：自进化 Agent（基于用户反馈数据自动优化 Prompt 和决策策略）
```

### Decision Engine

```
短期：规则 + LLM 混合
中期：基于历史数据训练分类模型（替代规则层）
长期：强化学习（以用户满意度为 reward，自动优化决策策略）
```

## 商业化路径

| 阶段 | 模式 | 核心用户 |
|---|---|---|
| MVP | 免费（有生成次数上限） | 早期种子用户，收集反馈 |
| Phase 1-2 | Freemium（Pro 订阅，解锁高级功能和更多次数） | 内容创作者、设计师 |
| Phase 3 | 平台抽成（模板市场）+ 企业订阅 | 设计师、企业客户 |
| Phase 4 | API 按量计费 + 企业私有化部署 | 开发者、大企业 |

---

## 护城河建设

真正的护城河不是"接了哪些 API"，而是：

1. **数据飞轮：** 用户的反馈数据 → 优化 Decision Engine → 更好的体验 → 更多用户
2. **Prompt 知识库：** 积累大量经过验证的高质量 prompt 和风格词库
3. **用户习惯：** Creative Brief + 项目历史让用户难以迁移
4. **社区内容：** 用户创作的模板、风格成为平台资产
